# STD-ETSY-002 — Etsy Listing and Search Standard

**Status:** proposed extension standard. **Refresh external rules before every release.**

## 1. Listing facts must come from approved artifacts

The commercial writer may use only verified component/file counts, sizes, editable features, page counts, age bands, format versions, and access requirements. Every material factual claim maps to a project artifact and hash. No fabricated customer proof, scarcity, outcome guarantee, competitor data, or search-volume value.

## 2. Current Etsy constraints to validate

The values below reflect official Etsy help/handbook pages reviewed on 2026-10-21 and must be rechecked before publishing:

- **Title:** maximum 140 characters. Etsy's 2026 guidance recommends a clear, buyer-friendly title, generally fewer than 15 words, naming the item and its most important traits; avoid repetitive keyword stuffing and subjective filler.
- **Tags:** up to 13 tags, each no more than 20 characters. Use relevant multi-word phrases, with purposeful variation. A candidate phrase longer than the limit must be rewritten or split into natural, useful phrases.
- **Digital files:** instant-download listings currently support up to 5 uploaded files, with a 20 MB per-file maximum. Confirm supported file types and current limits before release. If necessary, create well-organized ZIPs; do not assume ZIPs remove the underlying file-size/format constraints.
- **Digital variations:** Etsy help says variations are unavailable for digital listings. If a basic and expanded bundle have different contents or prices, prepare separate listings unless current official guidance confirms another suitable mechanism.
- **Fulfillment:** distinguish instant-download files from made-to-order digital fulfillment. Do not use an instant-download listing plan when a seller must edit the buyer's name/photo or create a custom file after purchase.
- **AI disclosure:** if the item is created with the use of AI, include the disclosure required by Etsy's current policy in the relevant listing description.
- **Seller originality:** the digital item must be made and/or designed by the seller and meet current Creativity Standards.
- **Personalization:** write precise instructions for customer-provided names/photos/files and state exactly how and when the delivered artifact changes. Follow current Etsy requirements for personalized listings.

## 3. Keyword strategy

- Prioritize the actual product noun and main buyer use case early in the title.
- Use tags for meaningful alternate wording, audience, occasion, format, and differentiating components, not repetitive near-duplicates.
- Use attributes and categories when available; don't invent a taxonomy path. Select the closest current Etsy category in the live listing UI.
- Do not assume every proposed tag is valid because it sounds natural; enforce the character limit mechanically.
- Do not claim that tags or title phrasing guarantee rank or sales.
- Keep search intent and product scope aligned: don't tag unrelated popular terms or use protected marks without rights clearance.

## 4. Description structure

Every description draft should make these details easy to find:

1. What the product is and who it is for.
2. Buyer benefit and distinguishing feature.
3. Exact included file list and contents/counts.
4. Page sizes, file formats, color/ink-friendly versions, editability, and software/account prerequisites.
5. How to download, access, edit, print, or use it.
6. What is not included; no physical product/shipping where applicable.
7. Printing/device limitations and any material safety or supervision notes.
8. Usage licence: personal/educational/commercial terms as actually cleared.
9. Accurate AI disclosure when required.
10. Support/fallback route and version/compatibility notes, where applicable.

Avoid claims such as “instant personalization” if the buyer only receives a template, “works with all printers” or “safe for every age” without evidence, and promises of guaranteed outcomes.

## 5. Listing-gallery plan

Plan an original, truthful image sequence. For each image state its purpose, exact feature shown, source asset(s), crop/readability check, and traceability to the delivered product. A useful sequence may include:

- Primary image: immediately understandable product outcome and item type.
- Contents overview: every major component and the exact counts.
- Detail previews: legible examples of cards/pages/templates.
- Format comparison: US Letter/A4, color/ink-friendly, editable/static, only where included.
- Use case / audience guidance: accurate, non-misleading context.
- How it works: access/print/edit steps where important.
- Included vs not included and digital-only reminder.

Use seller-created imagery/mockups that faithfully show the product; do not use other sellers' images, unlicensed stock, deceptive placeholder text, fake reviews, or renderings that imply a physical item ships when only files are sold. Refresh image requirements on Etsy's current policy page.

## 6. Preflight checks

A listing package must fail validation if:

- title exceeds the current hard limit;
- a tag exceeds 20 characters, there are more than 13 tags, or a tag is irrelevant/unsupported;
- description claims a component absent from the manifest;
- the file delivery mode conflicts with the fulfillment plan;
- the bundle count/price tier differs across title, image copy, description, manifest, and actual package;
- required AI disclosure or rights evidence is absent;
- the category is stale or asserted as official without checking the live category selector.
