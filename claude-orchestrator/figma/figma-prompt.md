# Autonomous Figma-to-Lumen Synthesis Protocol

This workflow coordinates the automated generation of high-fidelity React layouts and interactive Storybook stories from a Figma Dev Mode URL using live Lumen Design System schemas via MCP.

## Phase 1: Context Ingestion & Mapping
1. **Extract Identifiers:** Extract the `file_key` and `node_id` from the provided Figma URL parameter.
2. **Fetch Figma AST:** Call the Figma MCP tool (e.g., `figma/get_file` or `figma/get_node`) to extract the exact bounding boxes, layer hierarchies, names, styles, and custom properties.
3. **Inspect Tokens:** Identify color hexes, spacing values, and typography names tied to Figma variables/styles.

## Phase 2: Lumen Schema Alignment (MCP Cross-Reference)
1. For every structural layer or pattern found in the Figma node, query the `lumen-knowledgebase` MCP server:
   - Example query: `lumen/search_components` or `lumen/get_component_specs` for layouts, buttons, cards, forms, headers, or nav elements.
2. **Resolve Props:** Map Figma layout constraints (e.g., Auto Layout padding, alignment, gaps) directly to Lumen layout components (e.g., `<Box>`, `<Flex>`, `<Grid>`, `<Stack>`) using their exact, currently supported React property names fetched from MCP.
3. **Enforce Tokens:** Replace any hardcoded CSS style boundaries with verified Lumen CSS tokens or semantic variables (e.g., `var(--lumen-spacing-4)`, `color="brand-primary"`).

## Phase 3: Code Production & Storybook Scaffolding
1. **React Generation:** Write a production-ready component file into `src/components/[ComponentName]/[ComponentName].tsx`.
   - Use clean functional components with explicit TypeScript interfaces for incoming data or actions.
   - Restrict imports strictly to the verified `@cba/lumen-ui` paths returned by MCP.
2. **Storybook Generation:** Write a matching story file into `src/components/[ComponentName]/[ComponentName].stories.tsx`.
   - Build out comprehensive controls (`args`) for dynamic properties.
   - Recreate the exact layout variations or visual states (e.g., Active, Disabled, Loading) presented in the high-fidelity Figma file.

## Phase 4: Autonomous Validation
1. Internally review the synthesized component interface against the live Lumen API criteria fetched via MCP.
2. Ensure no non-Lumen atomic dependencies or raw inline styles are injected.
